# Stick Fury - Rage of the Stickmen

Original stickman action game: fight waves of stick zombies, ninjas, bombers and bosses,
earn coins, buy weapons and upgrades, hire ally gunners, and unleash RAGE.

- 12+ levels (endless scaling after 12), 7 themed worlds, boss every 4th level
- 6 enemy types, 3 bosses with different attack patterns
- 9 weapons: fists, spiked bat, katana, pistol, SMG, shotgun, sniper, rocket launcher, minigun
- Shop, upgrades (HP, damage, speed, allies), combo system, rage special, saved progress
- Touch controls on phone; keyboard on desktop (A/D move, W jump, J attack, Q swap, L rage, P pause)

## Play
- Browser: GitHub Pages link (Settings -> Pages) after the first push
- Android: download `StickFury.apk` from the **latest** release

## Develop
`npm test` runs a headless bot through many levels and bosses.
